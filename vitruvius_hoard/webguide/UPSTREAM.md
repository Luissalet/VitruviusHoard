# Web guide library: provenance

`guides/` holds the guide collection of the Modern Web Guidance project, copied unchanged.

- Source: https://github.com/GoogleChrome/modern-web-guidance (`skills/modern-web-guidance/guides`)
- Revision copied: `64a6d708f5a43f2cd3fde5d4d7db3905ba1bdf65`
- License: Apache License 2.0, text in `LICENSE-Apache-2.0.txt`. Copyright remains with the Chrome team and the contributors of the project.
- 210 guides in 17 categories. Nothing was removed or edited on disk; the reader rewrites the command-line cross-references into
  this library's own tools when a guide is read.

The legacy scan (`legacy.py`) is original code: its rules are written here and only point at the guides by id.

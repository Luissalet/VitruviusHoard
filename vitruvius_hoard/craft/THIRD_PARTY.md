# Craft library: provenance

`threeui_catalog.json` indexes the component catalogue of ThreeUI Community (https://github.com/MengTo/threeui, MIT License,
Copyright (c) 2026 Meng To): identifiers, labels, categories, descriptions, tags, runtime notes and the controls and variants of each
component, extracted from its catalogue data. The upstream component source, textures and media are not copied; the catalogue
records only where each component lives upstream (`source_files`).

The scenes, heroes, texture recipes, dashboard page and Blender script of this library are original implementations that use the
bundled three.js module (MIT, `vitruvius_hoard/showcase/assets/LICENSE-three.txt`).

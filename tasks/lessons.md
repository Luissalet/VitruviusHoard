# Consolidation lessons

- Follow Luis's ownership map: Cicero remains separate; Borges belongs to Writer, not Hypatia; HomeCook and PeopleDorian are not fused. This pack incorporates Babel and existing Theseus into Vitruvius only.
- Theseus is incomplete and paused by Luis due to usage. Carry every existing capability and its source-coverage limits, without treating integration as a resumption or completion of its research programme.
- Native factories may create stores and recover jobs. Static catalogues must never instantiate them; owner lifetimes begin only on explicit activation.
- Native file, directory, JSON-source and analysis hashes use distinct formats. Retain their identities separately, verify consumed bytes and never relabel a historical result under another source revision.
- A shared project can have several version-exact environments. Require the explicit linked environment per revision; a global most-recent default is not a project association.
- Preserve complete retained result documents, not only a path into an OFF engine. Verify the native analysis SHA before snapshotting its metadata and document.
- Cancel owned tasks once and shield/join cleanup. A canceled caller, OFF and close cannot interrupt async finally or advertise OFF before its resources stop. Draining admitted multi-step work needs its original owner admission until its final commit.
- ThreadPoolExecutor does not propagate ContextVars. Copy each native branch and share one descriptor Future per job across loops; pin endpoint/model/revision without serializing chat or allowing fallback.
- Local HTTP to an explicitly owned synthetic preview is legitimate isolated QA. Record ownership and closure, distinguish it from external personal services/models, and do not claim zero sockets. Root clarified this boundary after the original inherited preview tests ran; do not repeat successful runs just to pursue zero-network wording.
- Public source incorporates licences/provenance before adaptation. Exclude private SDK commits and never modify original repositories, actual data or installed runtimes.

# Vitruvius's Hoard

Taller local de software con diseño y proyectos de fuentes, documentación de APIs por versión y capacidades existentes de ingeniería inversa. Diseño, APIs e Ingeniería inversa son módulos nativos independientes; todos los módulos y automatismos empiezan apagados.

**El desarrollo de Theseus está incompleto y en curso; Luis lo reanudó el 20 de octubre de 2026.** Esta integración conserva las funciones disponibles, incluidas las comparaciones de mensajes WebSocket guardados y los recibos inmutables de cobertura, y no completa el alcance pendiente. Consulta la [sincronización de fuentes](docs/THESEUS-SYNC.md) y el [ledger conservado](software_native/theseus-limits.md).

Elige un proyecto de aplicación y su revisión de fuentes. Asocia uno o varios entornos Babel explícitos, comprueba un archivo contra el entorno elegido y conserva hallazgos exactos. Asocia un archivo o toda la carpeta de esa revisión a un proyecto/artefacto Theseus real, solicita una operación existente y conserva el resultado completo comprobado. IDs, revisiones, hashes nativos, entornos y procedencia sobreviven al apagado; una edición no cambia la identidad de un análisis anterior.

Siguen disponibles biblioteca de diseño, referencias/colecciones/patrones, render, crítica/lint, tokens, motion, diagramas/isométricos, edición/acciones/previews de aplicaciones y exportación independiente. Babel conserva indexación, lookup/checker, docs/docsets/locales y preguntas a documentación. Theseus conserva proyectos, artefactos, hallazgos, escenarios, comparaciones, análisis, sesiones, grabaciones, registros, handoffs y evidencias portables con sus requisitos y límites reales. Todo es código incorporado mantenido en Vitruvius, sin depender de repositorios o servidores retirados.

Instala dependencias propias: pip install -e .; opcionales [render], [vectors] y [runtime]. Ejecuta npm ci y npm run build en la raíz, babel_client/ y software_native/engine/ (Node22.19+). Arranque explícito: python -m vitruvius_hoard, puerto5191. VITRUVIUS_PROFILE_DIR contiene design/, babel/, theseus/ y software-links.db; VITRUVIUS_TOKEN_FILE conserva la identidad del puente. Consulta el inventario antes de activar datos reales.

# Taller de software

Vitruvius incorpora completos Babel y las capacidades existentes de Theseus junto a Diseño. Los tres módulos y sus automatismos empiezan apagados. El catálogo frío ofrece110 herramientas sin abrir motores, fábricas, recuperación, almacenes ni trabajadores. Los editores nativos siguen completos bajo /design/, /babel/ y /theseus/.

**El desarrollo de Theseus está incompleto y permanece pausado por decisión de Luis por cuota de uso.** Esta integración conserva las funciones disponibles y no completa ni reanuda su alcance pendiente. El aviso aparece en el espacio común y en el taller nativo. Consulta el [ledger de cobertura conservado](../software_native/theseus-limits.md); una operación enumerada no acredita que su motor opcional esté instalado ni que su aceptación esté completa.

Activa Diseño y crea o elige un proyecto de aplicación. La revisión, sus archivos y SHA256 pertenecen al proyecto nativo de Vitruvius; conserva edición, datos, previews y exportación independiente. Activa APIs y asocia el entorno Babel que corresponde a esa revisión: puede haber varios por proyecto. La comprobación usa ese ID explícito y conserva hallazgos, versión de fuente y hash de archivo. Una nueva revisión no vuelve actuales los resultados anteriores.

En Ingeniería inversa asocia un archivo, o elige '.' para toda la carpeta de fuentes de esa revisión, a un proyecto/artefacto Theseus real. El hash nativo del árbol y el hash JSON de Vitruvius se conservan como identidades distintas. Solicita una operación existente, consulta el trabajo y conserva el resultado. El documento completo de análisis se comprueba contra su SHA nativo y se guarda junto al trabajo; sigue legible con los motores apagados. Las funciones nativas de evidencias, escenarios, comparaciones, sesiones y handoffs permanecen disponibles. No se entrega automáticamente evidencia del lector al constructor.

UI, API y MCP comparten manejadores. Apagar deja de admitir trabajo nuevo y espera escrituras admitidas, trabajadores y finally asíncronos; stopping no se anuncia como off. La cancelación concurrente no cancela dos veces la limpieza. Una escritura enviada sin respuesta queda como outcome_unknown: consulta el estado antes de repetir; no se reenvía automáticamente. Los automatismos son opt-in y no reanudan trabajos históricos al descubrir capacidades.

Los LLM usan exclusivamente las Sparks a través del contrato Faustus938: primer Faustus configurado, endpoint/modelo/revisión exactos fijados por trabajo, credencial de familia y esquema/esfuerzo originales. La resolución compartida respeta la concurrencia y cada trabajo mantiene su selección. Claves del proveedor sólo en Faustus; sin alternativa local de texto, carga, cambio silencioso de modelo, relajación de esquema ni reintento HTTP. La aceptación real depende del despliegue de938. Embeddings, render y análisis nativos conservan sus capacidades independientes bajo demanda.

Dependencias propias: pip install -e .; opcionales [render], [vectors] y [runtime]. npm ci y npm run build en la raíz, babel_client/ y software_native/engine/. El motor Node requiere22.19+. python -m vitruvius_hoard inicia el propietario en5191; python mcp_server.py no arranca aplicaciones y llama al propietario ya activo indicado por VITRUVIUS_URL.

VITRUVIUS_PROFILE_DIR guarda design/, babel/, theseus/ y software-links.db. Conserva tokens, IDs nativos y copilot-space-id separados: no fusionar conversaciones ni regenerar identidades. El [inventario de migración](MIGRATION933.json) detalla lo que trasladará raíz. Procedencia/licencias: provenance/software/SOURCES.json y los avisos de los paquetes incorporados. El SDK privado de Babel no se ha importado. Tema, icono Vitruvius, Cinzel/Source Sans3 y marca común Faustus se mantienen.

Las pruebas sintéticas y compilaciones no acreditan calidad de un modelo real, todos los motores opcionales, completitud de Theseus, aspecto en navegador ni paquete instalado. Revisión independiente, CUA, migración coherente, alias, instalación y publicación corresponden a raíz. Esta tarea no ha cambiado datos, aplicaciones, modelos ni repositorios originales.
